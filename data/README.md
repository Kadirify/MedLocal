# Datasets

Everything under `data/` is gitignored except this file and `splits/`. Datasets are downloaded on demand into the Hugging Face cache.

| Dataset | Source | Licence | Access | Used for |
|---|---|---|---|---|
| PubMedQA | [qiaojin/PubMedQA](https://huggingface.co/datasets/qiaojin/PubMedQA), [pubmedqa/pubmedqa](https://github.com/pubmedqa/pubmedqa) | MIT | open | pipeline benchmark: text model training and evaluation |
| Lab explanations (synthetic) | generated by `medlocal build-lab-dataset` from `reference/analytes.yaml` with `qwen3:14b` (Apache 2.0) as teacher | project licence | committed under `data/synthetic/` | lab explainer training and evaluation |


## Splits

`splits/pubmedqa.json` holds the PubMedQA ids used for validation and test. The test ids are the 500 from the official `test_ground_truth.json`, so numbers are comparable with published results. The other 500 expert-labelled questions are the validation split. Training uses the separate machine-labelled `pqa_artificial` subset.

Regenerate with `uv run medlocal pubmedqa-splits --out ../data/splits/pubmedqa.json` from `training/`.

`synthetic/lab-explanations.jsonl` holds generated reports, never real ones. Values are drawn around the catalog's reference ranges and kept clear of critical limits. Each explanation was written by the teacher model with vetted background text and kept only if it passed every rule in `labs/explanation_checks.py`. The split is part of each row; test and validation rows are generated first so that growing the training split never changes them.
